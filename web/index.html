        The pipeline

        Never “LLM drives the browser.” Always: propose → validate → execute → verify. Deterministic where possible, LLM-assisted where needed.

        VAD / ASR

        Noise suppression, barge-in, streaming transcription starts the planner early.

        →

        Gemini NLU

        Intent, entities, confidence. Ambiguous? Ask — never guess blindly.

        →

        Planner

        Goal → validated task graph with success criteria. Retryable, resumable.

        →

        Policy

        Permission levels gate sensitive actions. Payments always confirm.

        →

        BrowserRuntime

        navigate · click · type · extract — typed actions, mock or Playwright sidecar.

        Failure classes → recovery policy

        Failure classes with recovery strategies
        ClassRecovery
        ELEMENT_NOT_FOUNDSelf-healing selector ladder: role+name → text → CSS → vision
        POPUP_BLOCKING_VIEWAuto-dismiss cookie banners, newsletter modals, chat widgets
        AMBIGUOUS_COMMANDClarification loop — ask, don't guess
        ACTION_VERIFICATION_FAILEDRetry → alternate selector → safely abort
        PAGE_TIMEOUTTimeout + retry, fall back to simplified extraction
        AUTH_REQUIREDPause task, notify user, offer manual mode
        CAPTCHA_REQUIREDNever bypass — pause and wait for the human
        NETWORK_ERRORProxy health check → automatic failover
        POLICY_BLOCKEDRefuse and explain — no retry
        04

        Guardrails

        Autonomy with permission levels. Sensitive actions always go through the human.

        LEVEL 1

        Read-only

        • Navigate, scroll, extract, go back, reload
        • No typing, no clicking, no purchases
        • Mutating actions are policy-blocked
        LEVEL 2

        Interactive

        • Fill forms, click buttons, extract
        • Payments / messages / deletions need confirmation
        • Verified after every action
        LEVEL 3

        Restricted

        • Checkout, payment, account changes, downloads
        • Each requires explicit confirmation
        • “No, stop” always wins — barge-in
