        02

        The pipeline

        Never “LLM drives the browser.” Always: propose → validate → execute → verify. Deterministic where possible, LLM-assisted where needed.

        VAD / ASR

        Noise suppression, barge-in, streaming transcription starts the planner early.

        →

        Gemini NLU

        Intent, entities, confidence. Ambiguous? Ask — never guess blindly.

        →

        Planner

        Goal → task graph with success criteria. Retryable, resumable, explainable.

        →

        Policy

        Permission levels gate sensitive actions. Payments always confirm.

        →

        Browser MCP

        navigate · click · type · extract — typed tools, validated before dispatch.

        →

        Verifier

        URL, DOM delta, network idle. Fail → retry, heal selector, or ask the user.

        Tier 1Accessibility tree — fast, semantic, cheap
        Tier 2Simplified DOM — buttons, links, inputs only
        Tier 3Vision fallback — screenshots only when semantics fail

        04

        Guardrails

        Autonomy with permission levels. Sensitive actions always go through the human.

        LEVEL 1

        Read-only

        • Open pages, scroll, extract info
        • No forms, no purchases
        • Default mode for new sites
        LEVEL 2

        Interactive

        • Fill forms, click buttons
        • Sign in with user approval
        • Verified after every action
        LEVEL 3

        Restricted

        • Payments, downloads, account changes
        • Explicit spoken confirmation required
        • “No, stop” always wins — barge-in
